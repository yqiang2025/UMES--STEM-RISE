Program Overview

Build research experience for graduate, medical, or professional school.

STEM-RISE gives UMES undergraduate students hands-on research experience in STEM-related fields. Students work with an approved mentor, participate in career-development activities, and strengthen their preparation for competitive graduate school applications.

Students may identify a research mentor whose work aligns with their academic and career goals. Mentors may include faculty members, researchers, or professionals, subject to program approval.

Eligibility

Who should apply

  • Current UMES undergraduate student in a STEM-related discipline.
  • Interest in research and STEM-related career pathways.
  • Strong academic potential and commitment to continued study.
  • Interest in graduate, medical, or professional school preparation.

Google Sheets Sync

Connect this form to Google Sheets

Replace the placeholder URL in the script at the bottom of this file with your deployed Google Apps Script Web App URL.

  1. Create a Google Sheet named STEM-RISE Applications.
  2. Create a tab named Applications.
  3. Add this header row: ID, Submitted At, First Name, Last Name, Email, Phone, Student ID, Department, Major, Academic Year, GPA, Graduation Term, STEM Area, Mentor, Research Interest, Goals, Housing Needed, Meal Plan Needed.
  4. Open Extensions → Apps Script.
  5. Paste the script below, then deploy as a Web App.
  6. Set access to Anyone with the link or the appropriate UMES account setting.
  7. Copy the Web App URL into GOOGLE_SHEETS_WEB_APP_URL.
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Applications");
  var data = JSON.parse(e.postData.contents);

  sheet.appendRow([
    data.id,
    data.submittedAt,
    data.firstName,
    data.lastName,
    data.email,
    data.phone,
    data.studentId,
    data.department,
    data.major,
    data.year,
    data.gpa,
    data.graduationTerm,
    data.stemArea,
    data.mentor,
    data.researchInterest,
    data.goals,
    data.housingNeeded,
    data.mealPlanNeeded
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({ status: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}
